# Checklist wdrożenia nowego klienta

## Od klienta zbieramy:

- [ ] Nazwa firmy
- [ ] Adres (ulica, kod, miasto)
- [ ] Telefony (główny + ewentualnie drugi)
- [ ] E-mail kontaktowy
- [ ] Link do Facebooka (jeśli jest)
- [ ] Link do Instagrama (jeśli jest)
- [ ] Logo (najlepiej PNG z przezroczystym tłem)
- [ ] Lista produktów do wrzucenia (opcjonalnie – nazwa, krótki opis, cena, zdjęcie)
- [ ] Preferowana subdomena (np. nazwa-firmy.stronyagd.pl)
- [ ] Czy chce własną domenę? (tak/nie)

## Co robimy my:

- [ ] Spersonalizowanie szablonu (dane + logo)
- [ ] Uzupełnienie produktów / promocji / magazynu (zależnie od pakietu)
- [ ] Utworzenie projektu w Cloudflare Pages
- [ ] Wrzućenie plików
- [ ] Podpięcie subdomeny + sprawdzenie HTTPS
- [ ] Test koszyka wyceny i formularza
- [ ] Wysłanie maila powitalnego z linkiem do strony
- [ ] (Biznes/Premium) Umówienie krótkiego szkolenia

## Po wdrożeniu:

- [ ] Zapisanie klienta w arkuszu (pakiet, data startu, data płatności, subdomena)
- [ ] Ustawienie przypomnienia o płatności
